# About me deck

Edit `about-me.marp.md`, then run `sh scripts/build_about_me_deck.sh` to generate the static page at `/about-me/`. The theme follows the browser's light or dark color preference and uses the same Inter/Source Sans 3 fonts, ink colors, blue accent, and section rules as the LucidCV resume. The licensed font files are served from `static/about-me/fonts/`.
