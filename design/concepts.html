On LLM reproducibility

Aritra Biswas · Mar 9, 2025 · 7 min read · LLM · GenAI

One of the major issue with LLM output is its consistency and reproducibility.

Setting up two instances of LLM with different configs

The reproducibility-oriented instance sets temperature to 0, seed to 42, and max tokens to 50. The second instance leaves these settings unset.

PythonCopy
consistent_llm = AzureChatOpenAI(
    temperature=0,
    seed=42,
    max_tokens=50
)

Generation without any context

Fifty outputs are generated with each configuration, without grounding context.

ConfigurationResult
ConsistentRepeated outputs; the results table contains seven distinct outputs.
Less consistentAll 50 outputs were unique.

Generation with context

With a short-story summary as context, 46 of 50 consistent outputs were identical; four differed by one character. All 50 less-consistent outputs were unique.
